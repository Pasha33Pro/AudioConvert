## Описание

AudioConvert решает частую задачу: необходимость сжать аудиофайлы высокого разрешения (FLAC, M4A) для экономии места на
диске или для совместимости с плеерами, поддерживающими только MP3.

Главная особенность инструмента - **отсутствие внешних Python-зависимостей**.Скрипт напрямую взаимодействует с системным
`ffmpeg`, что гарантирует максимальную скорость работы, стабильность и отсутствие проблем с установкой тяжелых
библиотек.

## ⚙️ Как это работает (Технические детали)

1. **Проверка окружения**: При запуске скрипт автоматически проверяет доступность `ffmpeg` в системном `PATH`. Если его
   нет, выполнение корректно прерывается с понятным сообщением.
2. **Работа с путями**: Используется современная библиотека `pathlib` для кроссплатформенного и безопасного управления
   файлами и директориями.
3. **Флаги FFmpeg**:
    - `-q:a 0` - обеспечивает переменный битрейт (VBR) наивысшего качества (эквивалент ~320 kbps CBR).
    - `-map_metadata 0` - гарантирует копирование всех тегов (исполнитель, альбом, год) и встроенной обложки из
      исходного файла.
4. **Обработка ошибок**: Если конвертация конкретного файла падает, скрипт не прерывает всю работу, а выводит обрезанное
   сообщение об ошибке (`stderr[:200]`) и переходит к следующему файлу.

## Возможности

- 🎵 Пакетная конвертация `.flac` и `.m4a` в высококачественный MP3
- 🏷️ 100% сохранение метаданных (ID3-теги и обложки альбомов)
- 📁 Автоматическое создание целевой директории `./mp3`, если она отсутствует
- 🚫 **Zero-dependencies**: работает только на стандартной библиотеке Python 3.10+
- 🛡️ Безопасная обработка ошибок без "падения" всего скрипта из-за одного битого файла

## Требования

- Python 3.10 или выше
- Установленный в системе **FFmpeg** и добавленный в переменную окружения `PATH`

> 💡 **Как быстро установить FFmpeg на Windows:**  
> Откройте терминал (PowerShell или CMD) и выполните одну из команд (при наличии менеджеров пакетов):  
> `winget install Gyan.FFmpeg`  *(рекомендуется)*  
> или  
> `choco install ffmpeg`

## Установка и использование

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Pasha33Pro/AudioConvert.git
   cd AudioConvert
   ```
2. Убедитесь, что установлен ffmpeg через cmd:
    ```bash
   ffmpeg -version
   ```
3. Поместите аудиофайлы (`.flac`, `.m4a`) в текущую директорию
4. Запустите скрипт
    ```bash
   python audioconvert.py
   ```
5. Готовые MP3 файлы появятся в папке `./mp3`
